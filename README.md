# Clone TabNews

Projeto desenvolvido durante o [curso.dev/ia](https://curso.dev/ia), do Filipe Deschamps, com o objetivo de construir um clone do [TabNews](https://www.tabnews.com.br/) do zero.

## Sobre o projeto

Este repositório reúne o código e a evolução do desenvolvimento de uma implementação própria do TabNews, acompanhando as aulas, práticas e desafios propostos ao longo do curso.
